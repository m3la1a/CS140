Questions

1. What is AJAX?

AJAX (Asynchronous JavaScript and XML) is a technique for creating interactive web applications. It allows web pages to update asynchronously by exchanging data with a web server behind the scenes.

2. Why do you put your JS Code in a separate file?

Putting JavaScript code in a separate file helps with organization, maintainability, and reusability. It allows you to keep your HTML clean and makes it easier to manage and update your code.

3. How do you use the inspector (DevTools) to debug your JavaScript? How do you find the line number of an error?

You can use the inspector (DevTools) to debug your JavaScript by setting breakpoints, logging messages, and stepping through your code. To find the line number of an error, look at the console output or the source code view in DevTools.

4. Do your form and fields have the same ids that your JavaScript uses? Does the Console show any errors? List your ids, and fix any errors before you submit.

Yes, my form and input fields have the same IDs used in my JavaScript: myForm, username, email, password, and response. I will check the Console for errors and fix any problems before submitting.
