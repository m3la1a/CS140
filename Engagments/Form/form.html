Basic Form Questions and Answers

1. Click each label. What happens?

Answer: When I click a label, the cursor moves to the matching input field.

2. Type in the password field. What do you notice?

Answer: The password characters are hidden and appear as dots or circles.

3. Click the submit button. What changed in the address bar?

Answer: The form is submitted, and the browser follows the action and method. With this example, the page may reload, but no information is sent to a real server.

HTML5 Form Controls







HTML5 Questions and Answers

1. What does the browser give you that a plain text box does not?

Answer: HTML5 controls provide special features like a calendar for dates, number arrows, and automatic input checking.

2. Does the keyboard change on your phone?

Answer: Yes. The keyboard can change depending on the input type. For example, number fields can show a number keyboard.

Questions and Answers

1. The form tag has an "action" attribute. What does it do?

Answer: The action attribute tells the browser where to send the form information after the user clicks submit.

2. The form tag has a "method" attribute. What does it do?

Answer: The method attribute tells the browser how to send the form information to the server.

3. What is the difference between POST and GET?

Answer: GET sends information through the URL, while POST sends information in the request body. POST is better for sensitive or larger information, but it still needs HTTPS for security.

4. How do you fill in a form control with a pre-set value, and how is that different from a placeholder?

  • Text box: Use value="Mela" to put in a pre-set value. A placeholder="Enter name" shows a hint that disappears when typing.
  • Textarea: Put the pre-set text between the opening and closing textarea tags. A placeholder shows a hint instead.
  • Select box: Add the selected attribute to the option you want selected by default.
  • Checkbox: Use the checked attribute to make it selected by default.
  • Radio button: Use the checked attribute to select one option by default.

5. List all the form controls that HTML5 added. Which ones did you put in your form?

Answer: HTML5 added these input types:

  • email
  • url
  • number
  • range
  • date
  • time
  • datetime-local
  • month
  • week
  • color
  • search
  • tel

I used email, date, number, and url in my form.
