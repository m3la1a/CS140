Why do we need a viewport meta tag? It makes the page use the device’s screen width and scale properly, so mobile layouts display at a readable size. If the same tag has flex-direction: column in one rule and flex-direction: row in another, which takes priority? The rule that comes later in the CSS takes priority, assuming both selectors have equal specificity and neither uses !important. How do you change the CSS for a web page displayed on a phone? Use a CSS media query, such as @media (max-width: 600px), to apply phone-specific styles. Pick a website you use on your phone. Name two things it changes on mobile compared to desktop. For example, YouTube uses a more compact navigation layout and stacks video details and recommendations in a narrower, single-column view. What width did you choose for your breakpoint, and why? I’d choose 600px as a starting point because it commonly separates narrow phone-sized layouts from wider layouts; adjust it to where the design needs to change.
