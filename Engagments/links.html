Absolute Link: General Conference

Explain the difference between an absolute link and a relative link. Why would you use relative links?

An absolute link is a full URL that includes the protocol (like http:// or https://) and the domain name. A relative link is a path that is relative to the current page's location.

Relative links are useful because they make your website easier to maintain and update. If you change the domain name, you don't have to update all the absolute links.
