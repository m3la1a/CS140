Explain the difference between inline, embedded, and external CSS.

Inline CSS is applied directly to an HTML element using the "style" attribute. Embedded CSS is written within the "style" tags in the HTML document's "head" section. External CSS is written in a separate "mystyle.css" file and linked to the HTML document using the "link" tag.

Explain why you should only use external CSS.

Using external CSS is recommended because it allows for better organization and separation of content and presentation. It makes it easier to maintain and update styles across multiple pages, as changes can be made in one CSS file rather than editing each HTML file individually. Additionally, external CSS can improve page load times by allowing browsers to cache the stylesheet.

What is a selector used for?

A selector is used to target and apply styles to specific HTML elements.
