    JPEG:

    Best for photographs with many colors, gradients, and fine detail such as portraits, landscapes, and everyday camera photos. It compresses files efficiently, but the compression can reduce image quality. (Real Life Pictures)

    GIF:

    Best for simple graphics with few colors, such as logos, icons, diagrams, and basic animations. It supports only a limited color palette, so it’s usually unsuitable for full-color photographs.

    PNG:

    Its distinctive feature is lossless compression, so it preserves image detail when saved. PNG also supports transparency, making it useful for graphics that need a transparent background.

    Resizing a photo:

    Use photo-editing software to set its pixel dimensions to match the size it will appear at on the page. If it will display at 600 × 400 pixels, for example, resize the image to roughly 600 × 400 pixels. Keep the original so you can create other sizes later.

    Why resize in editing software instead of CSS?

    CSS changes how large the image appears, but the browser may still download the full-size file. Resizing the image itself can reduce file size and loading time, and lets you control the quality and crop more precisely. CSS is still useful for responsive display and layout.
