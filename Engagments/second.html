Internet

The Internet is a worldwide network of connected computers and devices that communicate with one another and share information.

Web

The Web is a collection of linked pages and other resources that people access through the Internet using web browsers.

How are the Internet and Web different?

The Internet is the larger network that connects devices, while the Web is one service that uses that network to provide websites and web pages.

ASCII and Unicode

ASCII is an older character system that represents basic English letters, numbers, and symbols. Unicode is a much larger system that can represent writing systems and symbols from around the world.

What is UTF-8

UTF-8 is a common way of storing Unicode characters as bytes. It can represent many languages while remaining compatible with basic ASCII characters.

URL

A URL, or Uniform Resource Locator, is the address used to find a particular resource on the Web, such as a webpage, image, or file.

Domain Name

A domain name is the easy-to-remember name people use to reach a website, such as example.com, instead of typing its numerical IP address.

HTTP

HTTP, or Hypertext Transfer Protocol, is a set of rules that browsers and web servers use to request and send web content.

HTTPS

HTTPS is the secure version of HTTP. It encrypts information sent between a browser and a website to help protect it from being read or changed by others.

IP Address

An IP address is a numerical address that identifies a device or server on a network so that information can be sent to the correct location.

DNS

DNS, or Domain Name System, translates domain names into IP addresses so that browsers can locate the correct web server.
